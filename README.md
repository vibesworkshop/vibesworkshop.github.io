# VibesWorkshop Map

An index of the Vibes Lessons & Technique V-Book on [VibesWorkshop.com](https://www.vibesworkshop.com), Tony Miceli's vibraphone school: every lesson by topic, teacher and tune, a jazz concept map, a technique map, Tunes A–Z, a beginner path, and the 15 Week Vibe Course.

Nothing here is copied from the forum. Each lesson links to its post on VibesWorkshop.com, where the lessons, sheet music and videos are, behind the member login.

## The files

- `index.html`: the whole site, with pages switched by `#` links.
- `t/`: data that `index.html` loads as you browse.
- `.nojekyll`: tells GitHub Pages to serve the files as they are.

It's plain static files with no build step and nothing loaded from other sites. Any web host can serve the folder as it is. It has to be served by a web server, though: opening `index.html` straight from disk won't work, because the page loads its own files from `t/`.

To try it locally:

```
python3 -m http.server 8000
```

then open http://localhost:8000.

## Updating

The site is generated by `tools/build_website.py --link-out` in the VibesWorkshop archive project. Rebuild it there, then copy the output over these files.
